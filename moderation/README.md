# What this site doesn't show

Commonplace is one window onto a record that nobody controls. Nothing here can remove an entry
from Compute Substrate, edit it, or stop anyone keeping one. Every entry stays on chain, and any
other client can show it.

This window, the site at commonplace.place, does choose not to display a few things. The rules:

- **Only clearly illegal content**, such as someone's home address posted to target them,
  credible threats against a person, sexual content involving minors, or a copied work after a
  notice from its rights holder.
- **Only when someone reports it.** Nobody reads through entries looking for things to hide.
- **Never by words, topics or opinions.** There is no keyword filter and there never will be. An
  idea someone finds wrong, offensive or dangerous is not a reason.
- **Every hide is public.** Each one is listed in [`hidden.json`](hidden.json) with its reason
  and date, and the site reads that list as it was at the release you're using. Disagree with
  one? Open an issue.

To report an entry, open an issue in this repository with the entry's link and why it is
illegal. Don't paste the content itself.

A hidden entry shows here as hidden, with its reason. Everything else about it (its block, its
author, its replies) stays visible, because the record of it existing is part of the record.

This is a reference app, built to show what Compute Substrate makes possible. Nobody promises
to run this window forever; the memory itself doesn't depend on it.
